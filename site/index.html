03 · Narratives and mood

      
Memecoins trade in stories. Measure the rotation.

      
AI agents one week, dogs the next, politics around an election. Each token gets a theme from its name and symbol, and every theme gets heat, return and crowding, point-in-time. A market-wide risk-appetite score tells momentum when to step aside.

    

    

      

        
Narrative heat
The theme's share of volume now versus its usual share. Above zero, attention is rotating in.

        
Launch saturation
Copycat launches versus the usual pace. Above two, the theme is crowded and late tickers are exit liquidity.

        
Narrative return
Liquidity-weighted return of the theme, with rugs counted at −100%.

        
Risk appetite
Breadth, launch rate, death rate, volume impulse, buy pressure and curve progress, z-scored on trailing history.

        
External sentiment
Plug in X mentions, LunarCrush, Kaito or your own model. Every score waits for its publication lag.

        
No look-ahead labels
Names are fixed on chain at launch. Vendor categories are assigned later, often after the pump, so they never label history.

04 · What it does

      
Every tool a fund uses to stop fooling itself.

      
Rebuilt for a market where most tokens are dead within a day.

    

    

      
🪦
tests only tokens alive today
Point-in-time universe
Pools are recorded the moment they launch. Dead tokens stay in the panel, and a rug while you hold it is written off to zero. Token fields are known only from the moment they were observed.

      
💧
flat 1% slippage
Exact curve cost
Constant-product loss 1-(1-f)·Q/(Q+s) per trade, plus priority fee, MEV haircut and the pool's real fee tier.

      
🐋
size the pool can't absorb
Participation cap
A position is at most 2% of pool TVL. The book rebalances only past a 25% drift, so fixed fees don't eat it.

      
📈
"+120% alpha"
Alpha vs beta
Meme factors MKT, SIZE, MOM, AGE and FLOW, rugs included, and an OLS split of signal vs market.

      
🏦
"it scales"
Capacity curve
The same weights at $1k, $10k, $100k and $1M. Capacity is where return on capital halves.

      
🎰
keep the best of 50 tries
Deflated Sharpe
Every variant is written to SQLite. Significance is paid for with the honest trial count, and the counter can't be reset.

      
🚩
ignore who holds the supply
Rug screen
Holders, top-10 wallet share, mint and freeze authority, bonding-curve progress, all point-in-time. rug_screen() lets a strategy drop launches with a concentrated supply or a live mint authority.

    

  






  

    

      
05 · Pipeline

      
How a strategy gets killed.

      
Generation is cheap; validation is expensive. Claude is fast at ideas, so the system spends its effort on the part people skip.

    

    

      
01
Hypothesis
Claude proposes a signal from holder growth, flow, liquidity, age and curve progress.

      
02
Critic
A second Claude call attacks the idea before any compute is spent.

      
03
Sandbox
Generated code is AST-checked: numpy, pandas and the feature library only.

      
04
Backtest
Long-only, point-in-time, curve costs, MEV, 2% of TVL, rugs to zero.

      
05
Gates
Deflated Sharpe over every trial, then correlation and PCA against survivors. No overrides.

      
06
Tear sheet
Meme-factor betas, capacity, both halves, verdict.

    

    
every variant is written to SQLite · the trial counter cannot be resetREJECT luck · beta · loss   PASS real edge

Live terminal

      
Four memecoins on one screen. Every signal with its verdict.

      
Each window shows the chart and flow of one pool, the library's universe screen, what every strategy reads on that token right now with the zoo's verdict beside it, and what a ticket of your size would really cost: fee, curve slippage, MEV and priority fee, before you click. Trades go to a paper book that charges the same costs, and the account shows what selling everything now would actually return.

08 · Quick start

      
Running in a minute.

      
The demo needs no API key and no data. Research needs an Anthropic key and a few days of collected history.

    

    

      
install


git clone https://github.com/zostaff/quant-memcoins-researcher
cd quant-memcoins-researcher
python3 -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
cp .env.example .env    # ANTHROPIC_API_KEY for research

      
run


python -m ai_quant_lab.meme demo
python -m ai_quant_lab.meme run  --db data/meme.db
python -m ai_quant_lab.meme info --db data/meme.db
python -m ai_quant_lab.meme research --db data/meme.db \
       --network robinhood --iterations 20

      

        
demo
Tear sheets on synthetic tapes, no key or data needed.

        
run
Collect and refresh candles on every chain, forever.

        
research
Claude proposes strategies on your panel; the gates decide.

      

    

  






  

    

      
09 · Limits

      
What it does not do.

    

    

      
It does not trade
No wallet, no execution. It tells you whether a strategy is worth trading.

      
Costs are a model
Exact for bonding curves, conservative for concentrated liquidity. Calibrate on real fills.

      
Free data has gaps
Holder counts arrive late for fresh tokens; mint and freeze aren't reported on EVM chains.

      
History is collected
The panel knows only what the collector saw, from the moment it started.
